METHOD · 从图像问题到模型实现

模型结构与训练评测

01 / PROBLEM

图像去雾目标

雾霾会显著降低图像的对比度与色彩保真度，并影响下游视觉算法输入质量。目标是从单幅有雾图像重建更清晰、细节更自然的无雾图像。

02 / MODEL

SE-CGAN 网络设计

采用 Tiramisu 密集连接 U-Net 生成器重建图像，配合 70×70 PatchGAN 判别器约束局部纹理，使用 L1 重建损失、VGG 感知损失与对抗损失加权联合训练。

03 / EVALUATION

数据集与一致性校验

基于 RESIDE 合成雾图与 O-HAZE 真实雾图训练评测，记录 SOTS 离线指标 PSNR 28.05 / SSIM 0.9707，并校验导出推理权重与训练工程的一致性。

本个人主页保持纯静态架构，不自行接管文件上传或推理；点击下方按钮将在新标签页进入独立去雾演示服务，可拖拽上传、选择示例、滑动对比并下载结果。首次访问如遇容器冷启动，请稍候片刻。

接口 / 规格项 契约说明
GET /health 返回推理服务健康状态与运行设备信息（如 CPU）。
POST /dehaze 接收 multipart/form-data 字段 image（PNG / JPG，大小 ≤ 128KB）；服务端按最长边 256px 等比缩放推理，返回去雾后的 PNG 图像与 X-Processing-Time 耗时响应头。图片仅临时用于当次推理，不落盘留存。
错误状态码 异常返回 413（文件超限）/ 400（请求异常）/ 415（格式不支持）/ 500（推理失败）并附中文 detail 字段说明。
