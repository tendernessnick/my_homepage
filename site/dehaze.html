从图像问题，到模型实现

01 / PROBLEM

恢复对比与细节

雾霾降低图像的对比度与色彩保真度，也会影响视觉算法的输入质量。目标是从一张有雾图像，重建更清晰的结果。

02 / MODEL

生成与判别共同训练

条件生成对抗网络 SE-CGAN：Tiramisu 密集连接 U-Net 生成器重建图像，70×70 PatchGAN 判别器约束局部纹理。

03 / EVALUATION

让结果可以比较

使用 RESIDE 合成雾图与 O-HAZE 真实雾图训练、评测，记录 SOTS 测试集的 PSNR 与 SSIM，并校验导出权重与训练工程的一致性。

展开模型训练与推理说明

实现补充

训练采用 L1 重建损失、VGG 感知损失与对抗损失的加权组合。生成器负责重建无雾图像，判别器提供局部纹理约束。服务化后通过 FastAPI 接收 multipart 图片并返回 PNG，输入尺寸与上传体积受服务规格限制。
