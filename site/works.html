NoticeMe · 待办、提醒与日记

把随手想到的事情记下来，再在需要的时候提醒自己。一个本地优先的桌面工具，将待办、重复提醒和日记放进同一处，目前提供 Windows 版下载。

功能与实现 任务记录、提醒与本地 AI

记录用自然语言快速记任务，支持重复任务、日记记录、托盘与快捷键，减少在不同工具之间切换。

提醒置顶提醒卡、提示音与系统通知搭配使用，让提醒在桌面上有一个清晰的位置。

02 / Data Helper · 在线应用 · 2026.09

数据分析小助手 · Data Helper

从一张有问题的表格开始：导入、体检、清洗、可视化，再把干净数据交给主力分析软件。桌面版在本机处理，云部署版在服务容器内处理。

进入在线体验 GitHub 仓库 ↗ 读数据案例 ↗
功能与实现 体检规则、公开案例与看板扩展

产品纯本地规则体检引擎：0-100 质量评分 + 六维质量雷达 + 结构化问题清单，每个问题带一键修复；可检测列间算术关系违反与函数依赖冲突。

工程FastAPI + DuckDB + Parquet 列存 + Vue3 / ECharts；大 CSV 分块流式直写 Parquet（20 万行/块）；22 种清洗变换与多步版本回溯。

案例用 UCI Online Retail II 的 1,067,371 行零售交易跑通预处理：体检定位重复、格式和退货记录等问题，按本案例销售口径筛选得到 805,549 行记录；过程与结果随仓库公开。

扩展支持 MCP 协议外接 AI 客户端；运营看板扩展分支新增 KPI 卡、环比与口径说明、转化漏斗、结果钉卡和全屏放映，独立于当前在线体验版本。

网球天气助手（香港）· Weather Helper

面向全港 57 个公共网球场的降雨决策 PWA：在官方预报之上做二次评价，回答「这个球场的预报今天信不信」。

打开在线应用 ↗ GitHub 仓库 ↗
功能与实现 预报融合、实况验证与工程

产品融合天文台 SWIRLS 临近预报、Open-Meteo 集合预报与 ERA5 十年气候档案，输出 0-6 小时启发式降雨风险指数与「放心 / 边缘 / 别赌」决策建议；「去哪打」按时段找更干燥的球场，雨团地图查看降雨位置与走向。

闭环球友到场众包上报实况（地理围栏 + 冷却防刷），保留事前预报版本并与天文台测站双轨配对，比较各预报源的漏报、误报与误差表现（Brier）。

工程FastAPI + SQLAlchemy 定时调度 + React 19 / Vite / Tailwind 4；Web Push 开打前下雨提醒；80 项 pytest；Docker 云端部署，当前入口为 CloudBase。

04 / MailHelper · 双平台桌面工具 · 2026.10

邮箱管家 · MailHelper

从港校学生每天面对的校园邮件出发，做了一个 Windows / macOS 桌面管家：通过已登录的经典版 Outlook 同步邮件，自动分好类、标好轻重，重要通知不再淹没在收件箱里。

下载最新版 ↗ GitHub 仓库 ↗
功能与实现 分类规则、Canvas 日程与双端

产品七类自动分类（课程 / 职业发展 / 校园事务 / 财务缴费 / 通知 / 订阅 / 其他），分不准进「待确认」不默默分错；P0-P3 重要度标注，缴费截止与面试邀约一眼可见；改分一封，同发件人以后自动归对。

工程.NET 8 共享核心，Windows WPF + macOS Avalonia 双界面，EF Core / SQLite 本地存储；GitHub Actions CI 与双平台发布。分类在本机完成，不存邮箱凭据；支持自写分类规则和保存前试跑。

06 / CityU IS6335 · 独立完成 · AI 辅助 · 2026.11

纽约出租车运营分析与数据可视化

如果要在纽约开出租车，应该关注哪些时段、区域和业务？我在 AI 辅助下独立完成这一课程项目，从公开行程数据出发，处理数据、绘制图表，再把发现整理成运营分析与展示材料。

主分析使用纽约 TLC 2025 年 3 月约 414.5 万条黄车记录，经清洗保留约 380.2 万条有效行程；另整理 2015、2019、2021、2023、2025 年各四个月、共 20 个月的记录数面板，比较不同时期的行业需求。

Tableau 交互展示待接入查看简历条目

已完成 R 静态图表、分析与展示材料。Tableau 个人交互可视化完成后，将从此处开放参观。

Rggplot2sfigraphPython 指标复核

分析问题需求在一天内如何变化？哪些区域连接主要客流？机场业务、小费和账单构成呈现什么特点？通过时段图、地图与 OD 网络逐项分析。

一个发现2025 年 3 月有效行程中，JFK 固定价单占 2.73%，贡献 10.12% 的票面毛收入。这是值得进一步评估的业务线索；是否更赚钱，还需要等待时间、空驶与成本数据。

分析口径五个年份各四个月的记录数用于跨期对比，行程级结论限于 2025 年 3 月。按 RatecodeID = 2 识别 JFK 固定价单；票面毛收入按 fare_amount 汇总。
