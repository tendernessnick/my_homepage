01 / NOTICEME · 2026.11 独立开发 · AI 辅助 · Windows 版已发布

NoticeMe · 待办、提醒与日记

把随手想到的事情记下来，再在需要的时候提醒自己。面向待办分散、容易遗漏的个人用户，整合任务清单、今日计划、重复提醒与日记；个人数据完全保存在本机（JSON 原子写入与 7 份滚动备份）。目前 Windows 版已发布（不推断 macOS 已正式发布）。

  • 规则式快速记录与可靠提醒：支持“明天 9 点交周报”等自然语言创建任务，搭配置顶卡片、提示音、系统通知、延后提醒与未处理循环提醒；提醒调度不依赖模型。
  • 可选本地 AI 边界：本地 AI 能力默认关闭，用于长文本拆解待办、从日记提取任务或周回顾，所有提议须先预览确认后才保存。

02 / DATA HELPER · 2026.09 独立开发 · AI 辅助 · 已上线

数据分析小助手 · Data Helper

面向 Excel / CSV 分析前处理的规则体检工作台：导入、诊断、先预览后应用清洗、多步撤销与版本回溯、DuckDB SQL 查询与导出，支持 MCP 协议外接 AI 客户端（另维护独立运营看板扩展分支）。桌面版在本机处理，云部署版在服务容器内处理。

  • 纯本地规则体检引擎：0–100 规则评分与多维诊断清单，提供问题证据样本与一键修复入口，可检测缺失、重复、格式及列间算术关系与函数依赖异常。
  • UCI Online Retail II 真实留存案例：对 1,067,371 行零售交易明细按有效销售业务口径筛选至 805,549 行（8 列投影为 7 列，规则评分 83.4 → 77.5），揭示样本与列集合同时变化时不能把分差简单判为质量提升或退步。

03 / WEATHER HELPER · 2026.09 独立开发 · AI 辅助 · 已上线

网球天气助手（香港）· Weather Helper

覆盖香港 57 个公共网球场的出行降雨决策 PWA：整合香港天文台 SWIRLS 临近预报、Open-Meteo 集合预报与 ERA5 历史气候资料，按开打时间与 1/2/3 小时场次提供风险评估、「去哪打」时段选场、雨团地图与开打前 Web Push 提醒。

  • 事前快照与双轨验证：冻结开打前的预报版本，与天文台测站实测及球友现场上报（地理围栏 + 冷却防刷）配对，比较漏报、误报与误差（Brier）。
  • 诚实边界与无法判断提示：0–100 启发式降雨风险指数不是已验证的真实降雨概率，单小时峰值不等于整场降雨概率；当数据过期、缺失或覆盖不足时，明确提示“无法判断”，不宣称准确率提升。

04 / MAILHELPER · 2026.10 独立开发 · AI 辅助 · 双平台已发布

邮箱管家 · MailHelper

面向港校学生的 Windows / macOS 桌面校园邮件工具：通过已登录的经典版 Outlook 同步邮件，本机完成分类且不保存邮箱凭据，让缴费、面试邀约与课业截止不再淹没在收件箱里。

  • 七类分级与人工纠错沉淀：自动归入七类（课程 / 职业发展 / 校园事务 / 财务缴费 / 通知 / 订阅 / 其他）并标注 P0–P3 重要度；不确定邮件进入「待确认」不默默分错，人工纠正一封即沉淀同发件人规则，支持自写规则与保存前试跑。
  • Canvas 模板化截止同步：从已有 Canvas 模板化通知提取作业截止时间，按日期分组并提供临期提醒，合并重复通知并同步截止变更。（仅针对已有 Canvas 模板，不宣称可识别任意邮件）

05 / SE-CGAN · 本科毕业设计 视觉研究 · 独立在线演示

单幅图像去雾 · SE-CGAN

采用条件生成对抗网络（Tiramisu 密集连接 U-Net 生成器 + 70×70 PatchGAN 判别器，L1 重建 + VGG 感知 + 对抗损失联合训练）解决单幅图像去雾问题，并完成从 PyQt6 桌面端到 FastAPI + Docker + CloudBase 独立推理服务的工程交付。

  • 离线评测口径：基于 RESIDE 合成雾图与 O-HAZE 真实雾图训练，SOTS 测试集离线记录 PSNR 28.05 / SSIM 0.9707，并校验导出权重与训练工程一致。
  • 在线推理口径（与离线分开说明）：独立演示服务支持 PNG/JPG ≤ 128KB，服务端按最长边 256px 等比缩放推理返回 PNG，不留存上传图片；示例图效果不代表所有真实图片表现。

06 / CITYU IS6335 · 2026.11 独立完成 · AI 辅助

纽约出租车运营分析与数据可视化

围绕“如果要在纽约开出租车，应重点关注哪些时段、区域与业务”展开分析。在 AI 辅助下独立完成问题定义、R 数据清洗与静态可视化、Python 关键指标复核及展示答辩材料整理。

  • 数据范围与口径：主分析使用纽约 TLC 2025 年 3 月 4,145,257 条黄车行程记录，经 R 清洗保留 3,801,542 条有效行程；另整理 2015、2019、2021、2023、2025 五个代表年份各 3/6/9/12 月共 20 个月度记录数观测（非连续 20 个月、非全年）支持跨期对比。
  • 核心发现与边界：2025 年 3 月有效行程中，JFK 固定价单（RatecodeID == 2）有效行程占比 2.73%、票面毛收入占比 10.12%（分母为 fare_amount，区别于 total_amount 与净利润；是否更赚钱仍需等待时间、空驶与成本数据验证）。
