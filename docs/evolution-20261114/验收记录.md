## 本轮修复的真实细节

- 去雾面板移除旧入场动画带来的旋转，保留清楚的真实图像比较。
- NoticeMe 的 HTML 高度属性此前使预览异常增高；响应式高度已恢复。
- 页脚旧 flex 布局和高优先级 11px 规则曾压缩新姓名刊头，现已修正。
- 首页模式开关移入导航，避免固定按钮遮挡内容；窄屏目标至少44px。
- 页头使用固定定位并为正文保留准确占位；修复 sticky 内按钮通过 Tab 获焦时预滚动、导致模式记住错误阅读位置的问题。桌面/手机均验证原生点击和键盘路径。
- 搜索框的原生 `type=search` 会先消费 Esc 清除查询；现明确关闭模态并同步恢复滚动锁与焦点。
- 快速关闭再打开搜索时，旧 close 事件不再解除新模态的锁定。
- 输入法组合输入期间不接管 Enter、方向键或 Esc，避免中文候选确认时误打开结果。
- 长搜索结果采用可收缩的独立滚动区域，避免外层固定上限截断末尾结果和操作提示。
- 中文页使用静态 EN 入口，JavaScript 加载失败时仍能抵达英文页。

## 验证边界

本轮浏览器自动化主要使用本机 Edge / Chromium。响应式视口、模拟触摸事件和减少动态效果模式可验证结构与状态，不能替代 iOS/Android 真机触摸、VoiceOver/NVDA 人工读屏或所有浏览器兼容性测试。浏览器打印仅核查打印媒体样式，不把它称为重新制作并校对的简历 PDF。

外部服务的 HTTP 探测见 [招聘路径审查](招聘路径审查.md)。Data Helper、去雾在首次503后复查200；天气旧域404、新域200并回填。可用性会随服务状态变化，本轮未改动或部署后端。
