## 实际观察到的访问摩擦

1. 首次浏览器访问会显示 CloudBase 的“页面访问提示”：说明该地址为开发测试域，提供“确定访问”按钮。本次按公开按钮继续后进入应用。这层中间页不是作品截图中的应用界面，不应把它裁成应用预览。
2. 一次成功加载后，真实首页、CSS 和主 JavaScript 资源均已观察到；当次没有捕获到页面脚本错误。截图记录的 57、1%、0、0 等数值仅描述该时刻页面所示，不用作产品使用成果或持续服务可用性的证据。
3. 随后尝试手动进入球场列表与 Victoria Park 详情，但若干独立访问中出现初始导航超时，或应用标题/CSS已到而主 JavaScript 资源未在观察窗口内完成、正文仍为空。最长额外观察窗口为 60 秒。**本次没有可靠取得球场详情或逐小时预测截图，因此不交付假造的详情界面。**这只记录本次浏览环境的现象，不能据此推断所有访客都会遇到相同问题。
